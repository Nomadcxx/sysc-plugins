# Notes and Sticky Notes Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship a searchable Markdown vault manager and independent, shell-managed colored sticky notes that remain ordinary Obsidian-editable files.

**Architecture:** Extend the plugin wire contract with bounded floating surfaces, then host those views through sysc-shell's existing Wayland layer-surface owner. The shell owns surface geometry, focus, pin layers, and lifecycle; the Notes process owns note files, per-note edit buffers, search, and note colors. Work in separate plugin and shell worktrees, with a temporary Go workspace for local integration.

**Tech Stack:** Go 1.26, sysc-shell plugin/v1 JSONL protocol, existing `wlr-layer-shell` Wayland path, shell UI tree and software renderer, filesystem-backed Markdown.
