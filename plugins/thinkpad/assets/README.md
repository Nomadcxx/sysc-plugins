# ThinkPad wordmark

`thinkpad.png` is Lenovo's white wordmark with the red dot. The image comes
from [Lenovo Tech Today](https://techtoday.lenovo.com/gb/en/solutions/media/image/logo-thinkpadpng-0)
and keeps the source file's 94×34 proportions. The panel and bar scale it
without cropping.

Lenovo and ThinkPad are trademarks of Lenovo Group Limited. This plugin is an
independent project.

The bundled white version suits the shell's dark surfaces. To use another
version, set **Custom logo image** in plugin settings to an absolute PNG path.
The panel uses a laptop icon when that path is empty, missing or unreadable.
